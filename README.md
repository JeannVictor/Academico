# 📚 AEDs III - Algoritmos e Estruturas de Dados III

Bem-vindo ao repositório de **Algoritmos e Estruturas de Dados III (AEDs III)**!
Este repositório reúne os trabalhos desenvolvidos durante a disciplina, com foco em grafos, NP-completude e problemas de otimização combinatória, utilizando a linguagem **C**.

![Linguagem C](https://img.shields.io/badge/Linguagem-C-blue) ![Licença MIT](https://img.shields.io/badge/Licen%C3%A7a-MIT-green)

---

## 🏗️ Estrutura do Repositório

### 📝 [Trabalho 1 — Prova de NP-Completude](./trabalho_1)

Trabalho teórico: escolha de um problema NP-Completo, estudo da prova original de sua NP-completude e reprodução com as próprias palavras. Sem código associado, apenas enunciado e o relatório entregue (`paper.pdf`).

### 🛠️ [Trabalho 2 — Caixeiro Viajante](./trabalho_2)

Implementação em C do Problema do Caixeiro Viajante (TSP) por força bruta, com instâncias de teste em formato `.tsp`.

### 🛠️ [Trabalho 3 — Análise de rede de personagens](./trabalho_3)

Construção de uma rede de relacionamento entre personagens de "A Storm of Swords" (Game of Thrones) a partir do texto bruto, com cálculo de componentes conexos e centralidade de intermediação (algoritmo de Brandes), além de um script Python para visualização interativa do grafo.

---

## 🖥️ Linguagem Utilizada

Os códigos deste repositório estão escritos em **C** (com um script auxiliar em **Python** para visualização de grafos no Trabalho 3).
