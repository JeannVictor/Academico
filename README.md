# 🖼️ Processamento de Imagens

Bem-vindo ao repositório de **Processamento de Imagens**!
Este repositório reúne os códigos desenvolvidos durante as aulas e o trabalho final da disciplina, em **C**.

![C](https://img.shields.io/badge/C-00599C?style=for-the-badge&logo=c&logoColor=white)

---

## 🏗️ Estrutura do Repositório

### 🛠️ [codigos](./codigos)

Códigos em C desenvolvidos durante as aulas e listas de exercícios, organizados por capítulo/lista (`cap_2/`, `lista_1/`) e um código de detecção de bordas (`sobel.c`). São exemplos avulsos, sem projeto/build formal.

### 🚀 [trabalho_final](./trabalho_final)

Trabalho final da disciplina: codificação e decodificação de contornos de imagens binárias usando código de cadeia (chain code). Ver README próprio.

---

## 🎯 Objetivo do Repositório

Este repositório documenta a implementação prática de algoritmos de processamento de imagens estudados na disciplina.
