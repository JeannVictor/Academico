# 🤖 Inteligência Artificial

Bem-vindo ao repositório de **Inteligência Artificial**!
Este repositório reúne as atividades práticas e o trabalho final desenvolvidos ao longo da disciplina, em Jupyter Notebook.

## 🏗️ Estrutura do Repositório

### 🛠️ [atividades](./atividades)

Atividades práticas em Jupyter Notebook, divididas em:
- [enunciados](./atividades/enunciados) — notebooks com os enunciados das atividades (árvores/random forest, reconhecimento de dígitos, RNN/LSTM, técnicas de melhoria, transfer learning/transformers, câncer de mama, k-means).
- [resolucoes](./atividades/resolucoes) — notebooks com as resoluções correspondentes.

### 🚀 [trabalho_final](./trabalho_final)

Projeto final: pipeline de machine learning aplicado ao dataset de qualidade de vinho tinto. Ver README próprio.
