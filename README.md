# 🔄 Gestão do Ciclo de Vida de Software

Bem-vindo ao repositório de **Gestão do Ciclo de Vida de Software**!
Este repositório reúne os laboratórios práticos de persistência de dados em Java e o projeto final da disciplina, uma aplicação web completa.

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white) ![Spring Boot](https://img.shields.io/badge/Spring%20Boot-6DB33F?style=for-the-badge&logo=springboot&logoColor=white) ![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

---

## 🏗️ Estrutura do Repositório

### 💾 [persistencia/jdbc](./persistencia/jdbc)

Laboratórios práticos de acesso a banco de dados via JDBC: conexões, prepared statements, transações, result sets, tratamento de exceções, entre outros. Inclui scripts SQL e diagramas UML de apoio. Ver README próprio.

### 💾 [persistencia/jpa](./persistencia/jpa)

Laboratórios práticos de mapeamento objeto-relacional com Jakarta Persistence API (JPA), organizados em mini-projetos Maven progressivos. Ver README próprio.

### 🚀 [trabalho_final/BlueVelvet](./trabalho_final/BlueVelvet)

Projeto final da disciplina: **Blue Velvet Music Store**, aplicação web Spring Boot para uma loja de discos, com autenticação de usuários e gerenciamento de categorias hierárquicas de produtos. Ver README próprio para detalhes de arquitetura e como rodar.
